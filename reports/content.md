## 모델 개요

본 연구에서는 네트워크 패킷을 일반 패킷과 공격 패킷으로 분류하기 위해 Hidden Markov Model(HMM)을 사용하였다.  
입력 데이터는 패킷의 byte sequence이며, 이를 관측열로 사용하고 숨은 상태는 패킷 내부의 잠재적인 순차 패턴을 나타내도록 구성하였다.

## 모델 구조

HMM은 초기 상태 확률((pi)), 상태 전이 확률 행렬((A)), 관측 확률 행렬((B))로 구성된다.

- (pi): 시퀀스 시작 시 각 상태에 있을 확률.
- (A): 이전 상태에서 다음 상태로 이동할 확률.
- (B): 특정 상태에서 특정 byte가 관측될 확률.

이때 byte sequence는 이산 관측값으로 처리되며, 각 byte는 관측 기호로 매핑된다.  
숨은 상태는 여러 개의 잠재 상태로 설정하여 패킷 내부의 시간적, 순차적 특성을 반영한다.

## 학습 방식

일반 패킷과 공격 패킷을 각각 하나의 클래스로 두고, 클래스별로 HMM을 별도로 학습하였다.  
즉, 일반 패킷 전용 HMM과 공격 패킷 전용 HMM을 각각 구성한 뒤, 새로운 패킷이 입력되면 두 모델의 우도(likelihood)를 비교하여 더 높은 값을 갖는 클래스로 분류하였다.

학습 과정에서는 관측된 패킷 시퀀스로부터 전이 횟수와 관측 횟수를 기반으로 초기 파라미터를 설정하고, 이후 반복적인 갱신을 통해 모델 파라미터를 최적화하였다.  
데이터가 희소하거나 특정 상태의 관측이 부족한 경우에는 Dirichlet prior를 사용하여 확률 추정의 안정성을 높일 수 있다.

## 분류 기준

테스트 패킷 (O)에 대해 일반 패킷 HMM의 우도 (P(O mid lambda_{normal}))과 공격 패킷 HMM의 우도 (P(O mid lambda_{attack}))를 계산한다.  
이후 다음 기준으로 최종 분류를 수행한다.

- (P(O mid lambda_{attack}) > P(O mid lambda_{normal})) 이면 공격 패킷으로 분류.
- 그 외에는 일반 패킷으로 분류.

즉, 최종 출력은 이진 분류이지만, 모델 내부는 다중 상태를 갖는 HMM 구조로 설계된다.

## 보고서에 포함할 수치

보고서에는 다음 수치를 함께 정리하는 것이 좋다.

- 상태 수: hidden state의 개수.
- 관측 기호 수: byte를 몇 개 범주로 나누었는지.
- 전이행렬 크기: 상태 수 × 상태 수.
- 관측행렬 크기: 상태 수 × 관측 기호 수.
- 학습 데이터 수: 일반 패킷 수, 공격 패킷 수.
- 테스트 데이터 수.
- Accuracy, Precision, Recall, F1-score, ROC-AUC.
- 클래스별 likelihood 평균 또는 분포.

## 보고서용 문장 예시

본 연구는 네트워크 패킷의 byte sequence를 관측열로 사용하는 HMM 기반 분류 기법을 적용하였다.  
일반 패킷과 공격 패킷 각각에 대해 독립적인 HMM을 학습하고, 테스트 시퀀스에 대한 우도 비교를 통해 최종 클래스를 결정하였다.  
이를 통해 패킷의 순차적 특성과 잠재 상태 전이를 반영한 이진 분류를 수행하였다.
